# 🦊 Little Foxy — Foxy Tech

A fresh, lightweight personal command-center portfolio for Little Foxy.

## What it is

- 🦊 Foxy Tech visual identity
- ⚡ Single-file, fast-loading frontend
- 🤖 Interactive Foxy AI command console
- 🌐 Responsive mobile + desktop layout
